# capacitas.info

Statische Sicherung der Webseite **capacitas.info** von Michael Deck.

Bitcoin, Wirtschaft, Philosophie und Religion – Mission Statement, Texte,
Podcast und das Bitcoin-Tagebuch aus dem Jahr 2024.

Die Seite läuft eigenständig: alle Bilder, Schriften und Stylesheets liegen
im Ordner `assets/`. Es besteht keine Verbindung mehr zum ursprünglichen
Anbieter Jimdo.

Umfang: 142 Seiten.
